DI CUNG TAKICO — macOS
======================

Thu muc macos chi co 1 file can bam:

  Play Takico.command

Sau khi tai tu Google Drive (lan dau):

  1. Giai nen macos.zip
  2. CHUOT PHAI "Play Takico.command" → Open → Open
  3. Game mo trong Chrome/Edge

Lan sau: double-click "Play Takico.command"

Thu muc _takico chua du lieu game — khong xoa.

Neu van loi:
  xattr -cr /duong/dan/toi/macos

Yeu cau: macOS 12+, Chrome/Edge, webcam.
