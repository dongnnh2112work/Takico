# DI CUNG TAKICO — User Guide (Windows)

**Portable:** Copy the entire `windows` folder anywhere (USB, Desktop, another PC).  
Keep `Play Takico.bat`, `Stop Takico.bat`, and `_game` together in the same folder.  
No repo, Python, Node, or Internet required.

After copying, you only need **4 items**:

| | |
|---|---|
| **Play Takico.bat** | Double-click to play |
| **Stop Takico.bat** | Quit the game |
| **GUIDE.md** | This file |
| **VERSION.txt** | Build info |

The **`_game`** folder holds game data — **do not delete or rename** (may be hidden on Windows).

---

## Start

1. Double-click **`Play Takico.bat`**
2. If SmartScreen warns → **More info** → **Run anyway**
3. Allow **Camera** in Chrome/Edge
4. Tap idle screen or press **SPACE** to start

## Quit / restart

| Action | How |
|--------|-----|
| **Quit** | Double-click **`Stop Takico.bat`**, or close **Takico Server** window |
| **Reopen** | Run **`Play Takico.bat`** again |

## Requirements

- Windows 10 / 11 (64-bit)
- Chrome or Edge (Chrome recommended)
- Webcam
- No Python, Node, or Internet required after install
- **3 stages** per run (see `VERSION.txt`)

## Kiosk / booth

- Camera **1.5–2.5 m** from player
- Disable screen sleep during the event
- Shortcut **`Play Takico.bat`** to Desktop if needed

## Troubleshooting

| Issue | Fix |
|-------|-----|
| .bat won't run | Run as administrator; check antivirus |
| Missing `_game` | Re-copy the full `windows` folder |
| Camera error | Chrome → lock icon → Camera → **Allow** |
| Port 8765 in use | Run **Stop Takico.bat** then start again |
