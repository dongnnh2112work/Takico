# ĐI CÙNG TAKICO — Hướng dẫn sử dụng

Sau khi giải nén, bạn chỉ cần **2 mục** trong thư mục:

| | |
|---|---|
| **Chơi Takico.app** | Double-click để chơi |
| **HUONG-DAN-SU-DUNG.md** | File này |

Toàn bộ dữ liệu game nằm **bên trong** `Chơi Takico.app` — không cần mở hay chỉnh file khác.

---

## Khởi động

1. Giải nén **`Di-Cung-Takico-Offline.zip`**
2. Double-click **`Chơi Takico.app`** (icon logo Takico)
3. Lần đầu macOS có thể chặn → chuột phải → **Mở** → **Mở**
4. Cho phép **Camera** khi trình duyệt hỏi
5. Chạm màn chờ hoặc nhấn **SPACE** để bắt đầu

## Tắt / mở lại

| Thao tác | Cách làm |
|----------|----------|
| **Tắt game** | **Cmd+Q** hoặc menu trên thanh trên cùng: **Chơi Takico → Thoát Takico** |
| **Mở lại** khi đã chạy | Double-click `Chơi Takico.app` lần nữa (mở trình duyệt) |

## Yêu cầu

- macOS 11 trở lên
- Chrome / Edge / Safari (khuyến nghị Chrome)
- Webcam
- **Không cần** cài Python hay phần mềm khác

## Booth / kiosk

- Camera cách người chơi **1,5–2,5 m**, tránh ngược sáng
- Một người trong khung hình
- Tắt ngủ màn hình trong suốt sự kiện

## Sự cố

| Vấn đề | Xử lý |
|--------|--------|
| Không mở được | Chuột phải → **Mở**; hoặc Terminal: `xattr -cr ~/Downloads/Di-Cung-Takico-Offline` |
| Máy chủ không phản hồi | Mở bằng **Chơi Takico.app**, không mở file HTML bên trong app |
| Camera lỗi | Chrome → ổ khóa URL → Camera → **Allow** |
