# DI CUNG TAKICO — User Guide (macOS)

**Portable:** Copy the entire `macos` folder anywhere (USB, Desktop, another Mac).  
No repo, Python, Node, or Internet required.

## Folder layout

```
macos/
  Play Takico.command    ← double-click this (only file you need)
  _takico/               ← game data (hidden, do not delete)
```

## Downloaded from Google Drive?

1. Extract `macos.zip`
2. **Right-click** `Play Takico.command` → **Open** → **Open** (first time only)
3. Game starts in Chrome/Edge

Later runs: double-click **`Play Takico.command`**.

More help: `_takico/README-FIRST.txt` and `_takico/GUIDE.md` (this file).

---

## Start

1. Double-click **`Play Takico.command`**
2. First time after Drive download: **Right-click** → **Open** → **Open**
3. Allow **Camera** in the browser
4. Tap idle screen or press **SPACE**

## Quit / restart

| Action | How |
|--------|-----|
| **Quit** | **Cmd+Q** on browser |
| **Reopen** | Double-click **`Play Takico.command`** again |

## Requirements

- macOS 12+ (Monterey or newer)
- Mac Intel or Apple Silicon
- Chrome / Edge / Safari (Chrome recommended)
- Webcam
- **3 stages** per run (see `_takico/VERSION.txt`)

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Won't run after download | Right-click `Play Takico.command` → **Open** |
| Game won't start | Terminal: `xattr -cr /path/to/macos` then run command again |
| Camera error | Chrome → lock icon → Camera → **Allow** |
